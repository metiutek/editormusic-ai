# Security policy

medit runs locally and binds to `127.0.0.1` by default. If you find a vulnerability — for example
a way for a web page or a song file to run code, read files outside the project, or reach the
local server from another origin — please **do not open a public issue**.

Report it privately through
[GitHub security advisories](https://github.com/metiutek/editormusic-ai/security/advisories/new).
You will get an answer within a few days. Fixes go into the latest release.
