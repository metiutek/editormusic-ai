# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and ideas — not people. Harassment,
insults and discrimination are not tolerated. Report problems privately through
[GitHub security advisories](https://github.com/metiutek/editormusic-ai/security/advisories/new)
or to the maintainer; reports are kept confidential.
